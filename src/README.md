# S1 Semiconductor AI Analyzer - Source Code

This directory contains the entire source code for the multimodal AI application, split across the backend orchestration layer and the frontend dashboard.

## Directory Structure

```
src/
├── backend/          # FastAPI server, PostgreSQL DB models, ML orchestration, SHAP, and IBM Bob LLM integration
└── frontend/         # React dashboard for displaying wafer maps, batch monitoring, and root-cause analysis
```

### Backend (`src/backend`)
The backend is responsible for:
- Orchestrating inference across the PyTorch CNN (WM-811K) and XGBoost models (SECOM).
- Dynamically calculating SHAP feature importance for failing batches.
- Communicating with IBM watsonx.ai (Bob) to generate human-readable summaries and corrective actions.
- Storing all lot, process record, and prediction data in a PostgreSQL database via SQLAlchemy.

See [`src/backend/README.md`](backend/README.md) for detailed setup and run instructions.

### Frontend (`src/frontend`)
The frontend is built with React and Vite. It provides an interactive dashboard for process engineers to:
- Monitor upcoming and completed batches.
- View detailed failure probabilities and SHAP root-cause analysis.
- Visualize spatial wafer defect maps.
- Read executive summaries and corrective recommendations generated by IBM Bob.

See [`src/frontend/README.md`](frontend/README.md) (if available) for installation instructions.
